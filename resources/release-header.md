## Warnings, advisories, etc.
- **Do not report issues to TETR.IO issue report forums or staff while using TETR.IO PLUS. You _will_ get banned from the TETR.IO discord if you do so.**  
- **This is a third party game mod - it breaks things sometimes. Remove it if you're experiencing issues.**  
- This release is for desktop version %DESKTOP_VERSION. Contains packaged code from this version, so installing this effectively installs %DESKTOP_VERSION. The desktop client version is different from the game version. Installing on other versions may cause mismatches with native files, will cause TETR.IO update prompts to appear, and probably won't work. 

## Install instructions
- Download `%RELEASE_NAME` and extract `app.asar`
- Replace `resources/app.asar` with the unzipped version in your tetr.io installation folder.
    - On Windows, this is `C:\Users\<YOUR USERNAME>\AppData\Local\Programs\tetrio-desktop\resources`
- Run tetr.io desktop!

## Uninstall instructions
- Click the `Uninstall TETR.IO PLUS` button in the TETR.IO PLUS window, then click `ok`.
    - If this doesn't work, you can also manually restore the old `app.asar` file.
    - You can also reinstall TETR.IO Desktop using the [official installer](https://tetr.io/about/desktop/) to overwrite TETR.IO PLUS. The installer will not affect your game settings.
